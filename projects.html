Zero dependencies — runs entirely in the browser

Aurum Macro
Automated macro signal engine for XAU/USD

A scheduled service that scores eight independent macro and options-flow signals — real yields, DXY, VIX, COT positioning, and more — into a daily composite gold bias on a normalised scale, so a verdict means the same thing whether three or eight signals were available. Every call is written to an append-only track record and served over a REST API to a companion execution bot.

Private repository — Docker + Railway, runs on a daily cron
Eight independent signals scored into a ratio-scale composite bias
Append-only public track record — every past call is auditable, none are editable
Telegram alerts on every scan and on every bias reversal
301 tests passing, ruff and mypy strict clean
