TrustGiving
Financial system of record for a church

Built with the rigor of software that handles other people's money — an append-only audit log enforced at the database grant level, a two-person rule required for every cash transaction, and Postgres-native uniqueness for membership numbers and envelope codes.

Private client project — code not publicly shared
Append-only audit log — the app's database role cannot UPDATE or DELETE it
Two-person cash confirmation, enforced at both the API and the database
Atomic uniqueness via Postgres sequences, not application-level checks
User roles re-verified server-side on every request, never trusted from a token
Trade Expectancy Journal
Self-contained trading risk calculator

A standalone HTML tool for tracking manual forex and gold trades against a fixed-risk, fixed-R:R model, with live win-rate and expectancy (EV) calculation. No install, no server, no dependencies.

Zero dependencies — runs entirely in the browser
Live expectancy calculation: EV = (Win% × AvgWin) − (Loss% × AvgLoss)
Trades saved locally per device via localStorage
CSV export for further analysis in a spreadsheet
